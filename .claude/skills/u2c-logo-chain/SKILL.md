# U2C logo chain

Code: `web-app/src/v8/brand.js` (`B.logoPhase`, `B.logoEvents`, `B.logo`, `drawGlow`), `film.js chainsBody` + `dropBloom`. Art: `web-app/assets/u2c-links.png` (+ `-edge`), anchors `src/v8/links.js` (generated by `tools/extract_logo.py`, never hand-edit). Native: synced copy.

## The break / thread (KEEP AS IS: the user likes it)
- Cycle C beats (`logo.cycle` bars x 4, default 8). Clip opens half way (OUT half) so frame 0 shows the whole logo.
- Letter k (U, 2, C) threads IN over `[k*C/8, (k+1)*C/8)` in 8 crisp steps (links in chain order, clip = Voronoi Path2D per link), runs OUT over `[C/2 + k*C/8, ...)`. Whole links only, no alpha/dither; the ghost edge outline always stays (alpha 0.28/0.6).
- Lit link: the one being threaded (IN) / next to leave (OUT); `logo.hero` clip lights a link per half beat.

## Beat following (v9)
| feature | rule | param |
|---|---|---|
| glow | solid links redrawn at 1/4 res, `blur(2.2 + 1.2*bloom)` px, added with `lighter` (ALBEDO: accent halo, source-over) at alpha `0.55*glow` | `logo.glow` (x, default 1) |
| kick pulse | `glow = logo.glow * (0.35 + 0.8*kickEnv)`; kickEnv decays exp(-dt/0.14 s) from the quantised kick | - |
| runner | while a letter is fully in, ONE lit link steps along U->2->C, one link per 16th (`floor(t/(BEAT/4)) mod totalLinks`); the lit link glows double | `logo.runner` (bool) |
| drop bloom | in a drop section `0.35 + 0.65*exp(-(t - phraseDownbeat)/(2 beats))`: wider second blur `7 + 5*bloom` px | `logo.bloom` (x) |
| punch | scale `1 + 0.012*kick` (x2 on hero) | - |
Taste limits: no on/off strobing (every envelope is continuous), bloom alpha <= 0.5, NIGREDO glow stays grey (R=G=B), accent pixels <= 2 %. Never fade the letters; the glow is additive light, not opacity.

## v11 link physics (brand.js `B.logo`)
On every link step (grid unchanged, `logoPhase` untouched) the link that threads IN lands with a damped-spring settle (starts 16 logo px above its place, zeta 0.4, 0.2 s period, gone after 0.24 s); the link that runs OUT falls under gravity (7000 logo px/s^2, small sideways drift and spin, gone after 0.22 s, drawn even after its letter is fully out). Constants `SETTLE_*`, `FALL_*`. Only in `cycle` mode (not hero/full). Glow keeps its clip (settling links are extras). Stills: `LOGO=1 STEP=2 node tools/chain-stills.mjs <audio> nigredo 0.12 shots/logo`.

## v12 hero dwell
In the exe hero the logo stays fully threaded between an IN and an OUT: `logo.hold` bars (default 10, period 8 + 40 beats, offset 16 beats, so the break sits at ~13-17 s of a 30 s clip). `B.cycleBeat(beat, C, dwell, off)` maps the beat into the plain cycle, so every link step is still on the grid (`B.logoEvents(b0, b1, C, dwell, off)` feeds the sync test). `logo.hold` 0 = the old continuous cycle.
