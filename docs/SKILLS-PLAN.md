# SKILLS-PLAN: which skills and repos improve the U2C video and U2C Studio (research only, no code touched)
Date 2026-11-21. Read: PROMPT-v21 (draft `<skills>`), the 10 u2c-* skills, hyperframes/-cli/-registry, media-use, video-use, reverse-any-video, style-sampling,
and the READMEs, SKILL files and licences of the 12 repos. Rule used everywhere: **u2c-* skills and the PROMPT-v21 banned list win every conflict.**
Two things the draft `<skills>` section got wrong: it lists tweakpane/ozone-style repos as if they were skills, and it never says what to do when they disagree with the house rules (section 2).

## 2. Conflicts found and the resolution
| Conflict | Who says what | Resolution (house wins) |
|---|---|---|
| Fades | LottieFiles entrances = opacity+scale; hyperframes exits = "blur-out and fade 0.13-0.25 s"; ffmpeg-skill/video-use fades and crossfades; u2c = none | Elements appear/disappear whole: scale/position from a clip, hard end. Text exits by deleting backwards. Audio de-click fades of 30 ms (video-use rule 3) are audio only and allowed. |
| Overshoot on glass | Lottie Playful/Energetic 10-30 %; hyperframes `back.out(1.4)`; u2c schema has `backOut` | Glass = Lottie "Glass" row: 0 % overshoot, damping ratio 1.0. Add an editor lint: `backOut` on `window.*`/`dialog.*` paths is an error. |
| Camera ease | u2c-camera-cuts: power2.inOut; PROMPT: MD3 Emphasized in/decelerate; Lottie lists Emphasized (0.05,0.7,0.1,1) and Accelerate (0.3,0,1,1) | Glide wide = Emphasized decelerate (0.05,0.7,0.1,1). Exits that accelerate use the true MD3 Emphasized accelerate (0.3,0,0.8,0.15), not Lottie's looser (0.3,0,1,1). Standard (0.2,0,0,1) on screen. Register `md3Emph`, `md3Std`, `md3Acc` ease ids. |
| One take vs cuts | u2c-beat-preview-motion: "insert cut to a meter, hard cut default, home shot is the logo"; PROMPT: camera never cuts, one match cut | PROMPT. `camera.shot` only uses `push`; hyperframes "match cut on the click's rebound; new screen slightly large and settles" is the one allowed cut (the intro push). |
| 1-frame invert flash | u2c-beat-preview-motion allows `fx.flash` on a snare | Reads as glitch: default sheets must not generate it (keep the property, remove from presets). |
| Mono fonts | u2c-beat-preview-motion section 3/4 prescribe "mono micro"; web-app CSS and tweakpane use JetBrains/Roboto Mono; hyperframes typewriter uses ui-monospace | Banned in the video. In Studio chrome too (user rule is absolute): Instrument Sans + `font-variant-numeric: tabular-nums` for timecodes. Terminal words: Akira caps, Synkopy labels; block caret sized by `measureText`. |
| Elephant | u2c-chain-pendant + beat-preview-motion section 5 vs PROMPT ban | Do not draw it. Keep the skill for the follower maths only. |
| Typing vs "one change per beat" | beat-preview-motion pacing section 1 vs 1 char per 64th | A text line counts as one event (its start and end on the grid); chars are a pure function inside it. |
| Rendering pipelines | hyperframes `render` (Chrome capture) vs u2c `render.mjs` (wraps it) vs web WebCodecs export vs Remotion `render` vs video-use ffmpeg concat | One film function, two renderers (web export, native `render.mjs`). Never Remotion, never video-use concat. |
| Audio mastering | hyperframes `normalize-audio`, media-use mixing, ffmpeg-skill `loudness.py` vs clipdata.py (-14 LUFS, <= -1 dBTP) | clipdata.py masters; others only measure. SFX added after: re-measure and keep TP <= -1. |
| Safe zones | ffmpeg-skill TikTok 10/22/5/14 %; hyperframes 90 % action / 80 % title; house x 12-88 %, y 15-78 % | House (stricter). Use `look.py --safe tiktok` only as a second opinion. |
| `dead_stretch` warning | hyperframes check warns when >3 s nothing changes; arrival stillness is by design | Keep the warning if it fires on the settle; do not add drift to silence it. |
| Click ring | registry `agent-cursor` draws a ring; hyperframes lists click rings as a generated tell | No ring. Click = cursor squash 2-3 frames + sound + the target reacting. |
| Licences | AGPL/GPL (Olive, Kdenlive, Shotcut) | Ideas only. MIT/BSD (tweakpane, three, ffmpeg-skill, Lottie skill) may be used with their notice. Pixabay SFX: local only. |

## 3. Top 10 improvements to the final video
| # | Improvement | Skill / repo | Exact rule or pattern |
|---|---|---|---|
| 1 | Arrival settle, then dead still | Lottie (Glass 0 %, premium), hyperframes motion.md ("match cut on the rebound, new screen slightly large and settles", damping ratio 1.0), Remotion `damping:200` | scale `1 + 0.05*s`, `s(t) = (1 + w t) e^(-w t)` (critically damped, closed form), `w = 16 rad/s` = 98 % in 0.36 s, snap to exactly 1 at 0.4 s. After that no camera/transform term changes until the next key. QA: consecutive-frame difference of the camera layer = 0 in the still window (u2c-render-qa stills + `ffmpeg tblend,signalstats`). |
| 2 | Seeded intro (left / right / direct), window order, hook | hyperframes contract #4 (no unseeded random), u2c-cue-sheet | `rng = mulberry32(xmur3(seed + ':' + beatIndex))` written from scratch in `core.js`; draw order fixed (intro mode, first window, order, hook). Seed lives in `sheet.meta.seed`. QA: same seed twice = identical `ffmpeg -f framemd5`; 500-seed script asserts each intro mode >= 20 %, hero >= 2 visits, rack = 1, spectrum first < 60 %. |
| 3 | Edison block waveforms, LOW / MID / HIGH | u2c-waveform, u2c-meters, u2c-stage-palettes | block = 1/32 note (~140 wave3 columns at 128 BPM); height = max abs of that band over exactly that sample range; mirrored; no smoothing; edges on device pixels; kick lane bright on `onsets.kick`. Add `tests/test_blocks.py` (numpy, <= 1 LSB like the waveform test). Do not use the registry `waveform` block (WebGPU shader, not real audio). |
| 4 | Terminal words that type in and out | registry `typewriter` + `caret-swap`, hyperframes motion.md holds, u2c-beat-timing | chars shown = `floor((t - t0) / (beat/16))` (64th); block caret, hard on/off every 1/8; delete backwards 2x faster (exit 40-50 % shorter); hold = 0.5 s + 0.3 s per word, rounded up to whole beats; at 128 BPM/30 fps a 64th is 0.88 frame, so two chars on some frames is correct. Register start/end in `schedule()`. Text at >= 2.6 % of frame height (`check` `text_below_floor`). |
| 5 | "JOIN / CREATE PROJECT" dialog pop and kill on the click | Lottie entrance-exit (modal 300-400 ms, Premium start 95-98 %, Corporate 90-95 %) | scale 0.94 -> 1, `w = 18 rad/s`, full opacity from frame 1 (no fade); container first, title 2 frames later, buttons 2 frames after (follow-through 50-150 ms, stagger total < 500 ms); dialog dies on the click frame (hard end, exit = 0 frames). |
| 6 | Camera glide back wide | Lottie easing table, camera-cuts | one tween, `cubic-bezier(0.05,0.7,0.1,1)` over 1.5 beats ending on a bar line; blur peaks at the fastest frame (15-20 px full frame, horizontal-only; hyperframes motion.md); no second move until 100-200 ms stillness after landing (Lottie choreography). |
| 7 | Cursor that reads as a person | registry `dart-cursor`, `agent-cursor`, `cursor-zoom-follow`, Lottie distance scaling | path = arc (not straight); duration = base x (50 px 0.8, 100 px 1.0, 200 px 1.3, 300 px 1.5, 400 px 1.6), landing on a 32nd; click = scale 0.92 for 2-3 frames, no ring; the window/camera reacts on the click frame (cause then effect, like cursor-zoom-follow). |
| 8 | Choreography discipline on every visit | Lottie choreography (hero leads, 1/3 rules, sequence 25/35/40 %) | per visit: window forward, rest sinks (secondary), meters keep reacting (ambient); at most one third of elements animating at once; hold 0.3-0.75 s before the payoff (hyperframes). Outro: only dialog + cursor move. |
| 9 | Sound that proves the cursor | media-use SFX, hyperframes sound.md | `click.mp3` on every cursor click and on the dialog x; `pop.mp3` on the dialog; `key-press.mp3` on every 4th char (16th grid), 2-3 takes rotated; `error.mp3` trimmed to ~0.4 s on LAB TEST: FAILED if it is not harsh; peak lands 1 frame after the picture; then ffmpeg ebur128 again: -14 LUFS +-1, TP <= -1. No whoosh, no chime. |
| 10 | Final gate: loop seam, safe zone, phone read | ffmpeg-skill, hyperframes review.md, u2c-render-qa | (a) `look.py <mp4> --safe tiktok --at <6 key times>`; (b) `check.py <mp4> --platform tiktok` (aspect/fps/LUFS/TP); (c) seam: |frame N-1 vs frame 0| must not exceed the p95 step between adjacent frames (the idea behind `loop.py`'s seam report, without its crossfade); (d) `npx hyperframes snapshot --review` phone sheet at 360 px, describe each beat frame "as a stranger" (an object you must explain = P0); (e) mute-watch and 0.25x watch. Notes in the format `t - where - problem -> exact change - what stays`, ranked P0/P1/P2, merged into the director-notes file. |

## 5. Revised `<skills>` section (paste into PROMPT-v21.md)
```
<skills>
House rules win every conflict. Load a skill only for the job named; do not use a skill that is not listed.

Always (the house rules): u2c-beat-preview-motion (style; ignore its mono-font, elephant, hard-cut and invert-flash lines), u2c-beat-timing (every event on the 32nd grid, in schedule()), u2c-camera-cuts (pushes only, landing on a key), u2c-cue-sheet (new cue paths: seed, intro, dialog; keep web and native in sync), u2c-waveform + u2c-meters (Edison blocks come from the real audio and get a numpy test), u2c-stage-palettes (Nigredo R=G=B), u2c-logo-chain, u2c-render-qa (render, stills, parity, director notes). u2c-chain-pendant: maths only, the elephant is not drawn.

Render and review: hyperframes + hyperframes-cli (render contract, `check --json`, `snapshot --review` phone sheet, `audio --json`; never `normalize-audio`, clipdata.py masters). media-use: bundled SFX only (click, click-soft, key-press, pop, error trimmed); kept local, never committed. ffmpeg-skill: measure and look only (`check.py --platform tiktok`, `look.py --safe tiktok --tiles`, `loudness.py`); never its fade, crossfade or loop-crossfade options.

Patterns to copy (ideas, written fresh): hyperframes-registry typewriter / caret-swap / terminal-simulator (typing), dart-cursor / agent-cursor (click squash, no ring), cursor-zoom-follow (camera follows the click). Never `add` glitch, RGB split, CRT or chromatic items; never a monospace font.
LottieFiles motion-design: tables only (duration by element, distance scaling, stagger budget < 500 ms, 100-200 ms stillness after a settle, choreography, quality checklist). Ignore its opacity entrances and overshoot archetypes. Glass = 0 % overshoot.
Easing tokens: arrivals/dialogs critically damped closed form (w 16 to 18 rad/s, under 0.4 s); camera glide MD3 Emphasized decelerate (0.05,0.7,0.1,1); on screen MD3 Standard (0.2,0,0,1); exits MD3 Emphasized accelerate (0.3,0,0.8,0.15). Remotion and motiondivision: read for spring maths only, no dependency.

Web editor: tweakpane (live property grid, monitors; override its mono font), design:design-critique, design:accessibility-review, design:ux-copy.

Do not use: video-use, style-sampling, reverse-any-video (unless I give a reference clip), higgsfield-*, scenario-labs, three.quarks, react-postprocessing, react-three-rapier, three.js (unless a 3D meter returns), vstgui, ozone-mastering-suite (untrusted: never run it), generic taste/UI skills.
Licences: AGPL/GPL = ideas only. MIT/BSD may be used with notice. Pixabay SFX, Akira, Synkopy: never in the public repo.
</skills>
```
